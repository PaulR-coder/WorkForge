# SEO Optimization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make getworkforge.com discoverable on Google for field service, HVAC/plumbing/electrical, and Tampa-local search terms.

**Architecture:** Pure metadata changes using Next.js 16 App Router's built-in `metadata` export API. Two new static files (`robots.ts`, `sitemap.ts`) use Next.js's file-based route handlers — they auto-generate `/robots.txt` and `/sitemap.xml` at build time. JSON-LD schema is injected as a `<script>` tag directly in the landing page JSX.

**Tech Stack:** Next.js 16 App Router, TypeScript, `next` Metadata API (`Metadata` type from `next`).

### Task 4: Create robots.ts

**Files:**
- Create: `src/app/robots.ts`

Context: Next.js 16 App Router supports a `robots.ts` file at `src/app/robots.ts` that exports a default function returning a `MetadataRoute.Robots` object. Next.js auto-generates `/robots.txt` from it. The `allow` rules for specific paths take precedence over the catch-all `disallow: ['/']`.

- [ ] **Step 1: Create the file**

Create `src/app/robots.ts` with:

```typescript
import type { MetadataRoute } from 'next'

export default function robots(): MetadataRoute.Robots {
  return {
    rules: [
      {
        userAgent: '*',
        allow: ['/', '/pricing', '/help', '/terms', '/privacy'],
        disallow: ['/'],
      },
    ],
    sitemap: 'https://getworkforge.com/sitemap.xml',
  }
}
```

### Task 5: Create sitemap.ts

**Files:**
- Create: `src/app/sitemap.ts`

Context: Next.js 16 App Router supports a `sitemap.ts` file at `src/app/sitemap.ts` that exports a default function returning a `MetadataRoute.Sitemap` array. Next.js auto-generates `/sitemap.xml` from it.

- [ ] **Step 1: Create the file**

Create `src/app/sitemap.ts` with:

```typescript
import type { MetadataRoute } from 'next'

export default function sitemap(): MetadataRoute.Sitemap {
  return [
    {
      url: 'https://getworkforge.com',
      lastModified: new Date(),
      changeFrequency: 'weekly',
      priority: 1.0,
    },
    {
      url: 'https://getworkforge.com/pricing',
      lastModified: new Date(),
      changeFrequency: 'monthly',
      priority: 0.8,
    },
    {
      url: 'https://getworkforge.com/help',
      lastModified: new Date(),
      changeFrequency: 'weekly',
      priority: 0.6,
    },
    {
      url: 'https://getworkforge.com/terms',
      lastModified: new Date(),
      changeFrequency: 'yearly',
      priority: 0.3,
    },
    {
      url: 'https://getworkforge.com/privacy',
      lastModified: new Date(),
      changeFrequency: 'yearly',
      priority: 0.3,
    },
  ]
```
